# CHANGE Program Week 1 Module Mockup

A Moodle-style online learning module mockup designed to show how print-based wellness education materials can be converted into a structured digital learning experience.

## Live Demo

https://fbelsabah.github.io/change-program-week1-mockup/

## Purpose

This project was created as a sample online-learning module for participant-facing wellness education. It focuses on clarity, accessibility, content organization, and simple interactive learning elements.

## Features

- Structured course module layout
- Learning objectives
- Short lesson sections
- Weekly checklist
- Reflection prompt
- Mini quiz
- Participant instructions
- Responsive HTML/CSS design

## Skills Demonstrated

- Online learning content development
- Moodle-style course organization
- User-friendly design
- Technical writing
- HTML/CSS
- Accessibility-focused layout

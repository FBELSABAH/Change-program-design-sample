# CHANGE Program Moodle-Style Course Prototype

A Moodle-style online course prototype designed to show how print-based participant wellness materials can be converted into a structured, accessible, and user-friendly digital learning experience.

This project was created as a portfolio/application sample for the UPEI Student Assistant – Online Learning position. It demonstrates course organization, participant-facing design, digital resource creation, and basic interactive learning elements.

## Live Demo

https://fbelsabah.github.io/change-program-week1-mockup/

## Project Overview

The prototype simulates a Moodle-style course for the CHANGE Program, a health and wellness program focused on nutrition education, movement support, habit-building, and participant reflection.

The site begins with a “My Courses” style course overview page, then opens into a full participant course experience titled:

**2026S CHANGE Program: Healthy Lifestyle Foundations**

The course is designed to feel simple, welcoming, and easy to navigate for participants who may be accessing health education materials online.

## Purpose

The goal of this project is to demonstrate how existing print-based health and wellness resources could be reorganized into a clear online learning format.

This prototype focuses on:

- Converting static educational material into structured digital modules
- Creating a participant-friendly course layout
- Supporting self-paced learning
- Making course navigation clear and simple
- Including reflection, knowledge-checking, and progress-oriented elements
- Designing a course experience similar to Moodle/LMS environments

## Key Features

- Moodle-style “My Courses” landing page
- Course card with title, term, and progress indicator
- Full course homepage with participant-focused introduction
- Introductory video section
- Six organized course modules
- Expandable/collapsible module layout
- Weekly learning objectives and activities
- Nutrition, movement, habit-building, and reflection sections
- Course check-in quiz
- Calendar-style course block
- Program snapshot section
- Mobile-friendly layout
- Clear participant instructions and support-oriented language

## Course Structure

The prototype includes the following modules:

1. **Welcome to CHANGE**  
   Orientation, program expectations, and participant support.

2. **Getting Started with Healthy Habits**  
   Small behavior changes, realistic goal-setting, and weekly reflection.

3. **Nutrition Foundations**  
   Mobile-friendly nutrition education content and practical planning prompts.

4. **Movement and Exercise Support**  
   Supportive physical activity guidance and realistic movement planning.

5. **Reflection, Follow-up, and Support**  
   Participant reflection, barriers, next steps, and ongoing support planning.

6. **Course Check-in Quiz**  
   A short knowledge check covering the main ideas from the course.
